⚙️ Caching Operations

💡 How it works:

A Bloom Filter prevents cache penetration (queries querying keys that don't exist, hitting DB directly). It hashes the input using 2 hash functions to set bits in an array. * If any hash bit is 0, the key is 100% NOT in the system (blocked before hitting database). * If all bits are 1, the key is PROBABLY in the system (allowed to proceed to DB/cache).
